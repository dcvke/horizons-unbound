# The field guide

*A notebook recovered from a shelter on the western road. The cover is dry. Several pages inside are still warm.*

The first entry calls it weather. The next three cross that word out.

Welcome to the Horizons Unbound wiki. There are two ways through these pages. The journal follows one traveller's encounters with the four storms, with a little room left for things they never managed to explain. The playing notes give you the information needed to recognise a storm, change a setting or run a server.

The journal is original fiction written for this guide. Its traveller, shelter and recovered notebook are part of that story; the practical sections describe features present in the mod.

## A note on the numbers

Gameplay notes describe the checked 1.21.1 implementation and the shared documentation for the 1.20.1 builds. Values marked **default** can be changed by the server or modpack. An observation from someone else's world may therefore be perfectly real and still differ from yours.

For integration code, events, resource packs and data packs, use the [addon reference](../ADDONS.md). The [verification report](../VERIFICATION.md) records tested combinations and limitations. Return to the [project README](../../README.md) for downloads and build instructions.
