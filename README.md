# Horizons Unbound

Horizons Unbound is a work-in-progress Minecraft Java Edition 1.21.1 mod for NeoForge. It adds dimensional storms with End, Nether, Overworld, and Deep Dark effects, along with blocks such as the Reality Anchor and Hot Crust.

## Build from source

Install Java 21, then run the Gradle wrapper:

```powershell
.\gradlew.bat build
```

The mod JAR is written to `build/libs/`. For local development, use the Gradle `runClient` task.

## Project status

Development is ongoing. The internal mod ID is `horizons_unbound`. The current mod metadata says `All Rights Reserved`; choose an open-source license before making the repository public.
